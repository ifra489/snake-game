# Snake Game 🎮

A classic Snake Game built with **HTML, CSS, and JavaScript**. Playable on desktop and mobile devices with mobile control buttons.

---

## **Features**

- ✅ Keyboard controls for desktop  
- ✅ Mobile buttons for mobile devices  
- ✅ Pause / Resume functionality  
- ✅ Score and High Score tracking (saved in localStorage)  
- ✅ Timer showing how long you’ve been playing  
- ✅ Eating sound and Game Over sound effects  
- ✅ Smooth snake speed increase  

---

## **Project Structure**
```bash
snake-game/
├─ index.html # Main HTML file
├─ style.css # Stylesheet
├─ script.js # Game logic
├─ eat.mp3 # Eating sound effect
├─ gameover.mp3 # Game over sound effect
├─ README.md # Project documentation


```

---

## **How to Play**

1. Open `index.html` in a browser.  
2. **Desktop:** Use arrow keys to move the snake.  
3. **Mobile:** Use on-screen buttons to move the snake.  
4. Press **Pause** to pause/resume the game.  
5. Eat the food to increase your score.  
6. Avoid hitting walls or your own tail!
